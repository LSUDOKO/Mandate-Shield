# Mandate-Shield

A deterministic security checkpoint between an AI shopping agent and the moment a payment mandate gets signed.

Package manager: npm.

## Commands

- dev: `npm run dev`
- build: `npm run build`
- test: `npm test`

## Layout

- `apps/`
- `docs/`
- `packages/`
- `scripts/`
- `serverless/`

## Rules

- Run `npm test` before you say a change is done.
- Never commit secrets or `.env` files.
